# Contributing to LSDC-Yolo-Approach

Thank you for your interest in contributing to **LSDC-Yolo-Approach**!

## Great Places to Contribute

- Add reproducible training scripts and fold-splitting utilities.
- Refactor inline `%%writefile` scripts into importable Python modules.
- Experiment with OOF-optimized ensemble blending weights and calibration.

## Workflow

1. Fork the repository and create a branch (`feat/...` or `fix/...`).
2. Verify notebook cell syntax and keep large DICOM datasets or trained weights out of git.
3. Keep changes focused and avoid committing `.DS_Store`, API keys, model weights, or user-specific IDE state (`xcuserdata/`).
4. Open a pull request describing what changed and how you verified it.
